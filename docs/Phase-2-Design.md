# Phase 2 – OLED Display Integration

## Objective

Display real-time temperature and humidity from the DHT22 sensor on an SSD1306 OLED display.

## Hardware

- ESP32
- DHT22
- SSD1306 OLED Display

## OLED Connections

| OLED | ESP32 |
|-------|--------|
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |
