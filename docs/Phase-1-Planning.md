# Phase 1 – DHT22 Sensor Interfacing

## Objective

Read temperature and humidity from a DHT22 sensor using an ESP32.

## Hardware

- ESP32 DevKit V1
- DHT22 Sensor

## Connections

| DHT22 | ESP32 |
|--------|--------|
| VCC | 3V3 |
| DATA | GPIO 4 |
| GND | GND |

## Results

Successfully measured:

- Temperature
- Humidity

and displayed the values through Serial communication.

## Concepts Learned

- Digital Sensors
- GPIO Configuration
- ESP32 Initialization
- Serial Communication
- DHT22 Library
